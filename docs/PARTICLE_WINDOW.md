# 粒子玻璃窗 · particle-window.html

> 本文件是仓库内一个**独立的纯前端演示页**（与本 Android 项目无代码关联）：
> 一个半透明的圆角拟态玻璃小窗口，轻点即**以粒子形式消散**，再轻点**以粒子形式汇聚重铸**。
> 动效参考 HarmonyOS 7（鸿蒙 7）的窗口粒子消散 / 汇聚转场。

- 位置：仓库根目录 `particle-window.html`
- 形态：**单文件、零依赖、零构建**，双击或拖进浏览器即可运行（离线可用）
- 技术：原生 Canvas 2D + 少量 DOM（提示胶囊），全中文注释

## 交互

| 状态 | 画面 | 点击任意处 |
| --- | --- | --- |
| `solid` | 玻璃窗口常驻（呼吸浮动 + 周期扫光） | 从触点开始**消散** |
| `dispersing` | 碎裂波挖空窗口，像素化为粒子飞散 | **反向**：从粒子当前位置开始汇聚 |
| `dispersed` | 只剩动态壁纸与环境尘埃 | **汇聚重铸** |
| `reforming` | 粒子螺旋收束 + 窗口 blur-in 浮现 | **再次消散**（从当前位置） |

动画中途允许反向打断，所有反向都从粒子的**当前位置**继续，不会跳变。

## 视觉构成（自下而上）

1. **壁纸层**：9 个漂移光斑以 1/5 分辨率绘制在离屏画布，放大绘制天然柔化；叠加暗角。
2. **玻璃卡片层**（离屏合成，每帧重绘）：
   - 取景：把卡片区域的壁纸**带鼠标视差偏移**裁进圆角裁剪区，`ctx.filter = blur()` 模拟 `backdrop-filter`（不支持 filter 的浏览器自动降级为不模糊）；
   - 质感：上亮下暗白色蒙层 + 左上环境高光 + 左上→右下渐变描边 + 内描边；
   - 内容：鸿蒙风格播放卡（渐变图标 + 八角星芒、44 根渐变波形、进度条、播放控件、底部提示），预渲染到独立画布后合成；
   - 生命周期特效：碎裂波（`destination-out` 径向渐变挖洞）与周期扫光都烘焙进这一层，**粒子颜色与窗口画面严格一致**。
3. **粒子层**：`lighter` 加法混合。消散时约 1.2~1.5 万粒（按 DPR 自适应网格采样，上限 15000）。
4. **氛围层**：170 颗上浮尘埃（冷暖两色、闪烁）、触点涟漪环、重铸完成闪光。

## 动效设计（对齐鸿蒙 7 的关键决策）

- **消散 = 碎裂波 + 径向延迟**：粒子释放时刻与挖洞波前同为 `dist(触点)/对角线` 的函数——洞扩到哪里，哪里的粒子才起飞，视觉上"窗口从指尖碎开"。
- **飞行 = 爆散初速 + 湍流 + 上浮**：双频正弦湍流 + 随高度剪切的风场，叠加净上浮加速度（火星/沙尘感）；指数阻力收敛。逐粒子闪烁（高频正弦调制 alpha）与尺寸收缩。
- **汇聚 = 螺旋收束 + 错峰**：粒子从外围椭圆环带出发，绕各自"原位"沿螺旋线收束（`angle = a0 + swirl*(1-e)`、`radius = R*(1-e)`，e 为 smoothstep），边缘先动、中心后动。
- **重铸 = 双轨并行**：粒子落位瞬间"焊花"提亮放大后熄灭；同时窗口层以 `blur(15px)→0` + alpha 0→1 渐显——模糊窗口从尘埃里"凝结"出来，最后几像素内的粒子直接隐入清晰窗口之下。

## 关键参数（均在源码对应函数内，带注释）

| 参数 | 当前值 | 含义 |
| --- | --- | --- |
| `DISP_DUR` | 1.8s | 消散态总时长，超时进入 `dispersed` |
| 碎裂波时长 | `T/0.7` | 挖洞波前扫过全卡的时间 |
| 粒子寿命 | `age>1.42` 回收 | 释放后最长存活 |
| 爆散初速 | `120+rn*285+d*0.45` | d 为距触点的距离（px） |
| `REF_DUR + REF_EXTRA` | 1.18+0.42s | 汇聚总时长（含收尾判定） |
| 粒子行程 | `0.7+rand*0.42s` | 单粒螺旋飞行时间 |
| 重铸起点 | `T>0.45` 起、0.7s 完成 | 窗口 blur-in 渐显 |
| 采样步长 | `max(2, 3*DPR)` 起，粒子数 >15000 自动加大 | 粒子密度 |
| `CAP` | 26000 | 粒子数组容量上限 |

> 时间参数在调优轮中整体提速过一轮（约 -30%），如需更慢的"余韵感"按上表回调即可。

## 实现要点与坑

- **像素→粒子**：消散瞬间对合成层 `getImageData`，按网格采样（跳过 alpha<26 的圆角外像素），颜色加固定亮度补偿（+26）——`lighter` 混合下暗色几乎不可见。
- **home 烘焙**：粒子原位在世界坐标里烘焙（含当时的呼吸浮动偏移），此后窗口层与粒子层互不干扰。
- **反向打断**：`dispersing↔reforming` 互切时以粒子当前解算位置为起点重建参数（消散取 `home+offset`，汇聚取参数化轨道的 `x(p)`），速度给少量随机扰动，视觉连续。
- **性能**：粒子全部 `fillRect`（≤15k），颜色字符串在采样期预生成；背景 1/5 分辨率。桌面与中端手机浏览器可保持 60fps。
- **兼容**：`ctx.filter` 不支持时玻璃降级为无模糊取景（Safari 16.4-）；`pointerdown` 统一鼠标/触摸。

## 验证方式（无头浏览器截图）

用 Chrome headless 的虚拟时间预算可精确抓取任意动画帧，适合回归：

```powershell
$args = @("--headless=new","--window-size=1280,800","--virtual-time-budget=1500",
  "--screenshot=dispersing.png","file:///…/particle-window.html")
Start-Process chrome.exe -ArgumentList $args -Wait
```

（配合注入 `setTimeout(function(){onPress(x,y);},400)` 的临时副本可抓"点击后第 N 毫秒"的帧；
`onPress` 是全局函数，副本测完即弃。）
